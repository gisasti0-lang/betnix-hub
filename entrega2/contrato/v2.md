## P5 · Formato (modificado)
La salida no termina en consola. Debe persistir en dos destinos:
1. El Excel de origen, actualizando "Último contacto" y "Último mensaje".
2. Un archivo `resumen.json` publicado en GitHub Pages, con este schema:

```json
{
  "fecha": "YYYY-MM-DD",
  "timestamp": "ISO-8601",
  "chats_activos": 0,
  "respondidos": 0,
  "contactos_excel": 0,
  "resumen": [
    {"handle": "@x", "nombre": "...", "fecha": "DD/MM HH:MM", "mensaje": "..."}
  ]
}
```
